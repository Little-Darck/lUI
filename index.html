Conceptos básicos

La base de toda página web

HTML define la estructura y el contenido. CSS determina su apariencia y JavaScript añade interactividad.

01

HTML

Lenguaje de etiquetas que organiza textos, imágenes, tablas, enlaces, audio y video.

02

CSS

Define colores, tamaños, espacios, diseños responsivos y estilos visuales.

03

JavaScript

Permite crear contenido dinámico e interacción entre el usuario y la página.

Estructura

Etiqueta de inicio y cierre

Todo documento HTML comienza con <html> y termina con </html>. Se divide en una cabecera <head> y un cuerpo <body>.

<head>Información para el navegador
<title>Nombre de la pestaña
<body>Contenido visible
<footer>Pie de página o sección
<h1> – <h6>Títulos y subtítulos
<main>Contenido principal
documento.html HTML 
<html lang="es">
  <head>
    <title>Mi primera web</title>
  </head>

  <body>
    <h1>¡Hola!</h1>
    <p>Bienvenido a mi página web.</p>
  </body>
</html>
