Glosario Técnico de Competencias y TIC

TIC (Tecnologías de la Información y las Comunicaciones)

Conjunto de recursos, herramientas, equipos, programas informáticos, redes y medios que permiten compilar, procesar, almacenar y transmitir información.

Infraestructura TI

Base tecnológica compuesta por hardware, software, redes, centros de datos y servicios necesarios para operar y gestionar los entornos tecnológicos de una organización.

BIOS / UEFI

Firmware fundamental almacenado en la placa base que inicializa y comprueba los componentes de hardware al encender el equipo antes de cargar el sistema operativo.

Mantenimiento Preventivo

Conjunto de acciones periódicas de limpieza, revisión física y optimización lógica realizadas para evitar fallas futuras y prolongar la vida útil del equipo.

Mantenimiento Correctivo

Intervención técnica destinada a diagnosticar, reparar o reemplazar componentes de hardware o software que presentan una falla operativa.

Driver (Controlador)

Programa que actúa como puente entre el sistema operativo y un dispositivo de hardware específico para permitir su correcto funcionamiento.

Particionamiento de Disco

División lógica de una unidad de almacenamiento física (HDD o SSD) en secciones independientes para organizar sistemas operativos y datos.

Macro / VBA (.xlsm)

Conjunto de instrucciones automatizadas en Microsoft Excel (Visual Basic for Applications) que ejecutan tareas repetitivas con un solo clic.

Especificación de Requisitos TI

Definición formal y documentada de las características técnicas, funcionales y de rendimiento que debe cumplir una solución de hardware, software o red para satisfacer las necesidades de una organización.

ESD (Descarga Electrostática)

Transferencia repentina de electricidad estática entre dos objetos que puede dañar componentes electrónicos sensibles si no se usan medidas de protección como manilla antiestática.
